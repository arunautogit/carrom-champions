# 🎱 Carrom Champions - Super Web Edition

A standalone, high-performance HTML5 Canvas & Web Audio carrom game.

## Features
- **Modes**:
  - **Normal Mode**: Classic official Carrom rules (White coins, Black coins, Queen cover rule, AI Bot opponent, dynamic striker positioning and aiming).
  - **Fun / Diwali Crackers Mode**: 19 unique Diwali crackers (9 white, 9 black, 1 red queen finale) with particle explosions, audio layers, 100-Wala perimeter celebration, and Diwali Giftbox.
- **Striker Arsenal**: Multiple striker weights, frictions, restitution, and visual themes.
- **Board & Coin Themes**: Lathe-turned 3D wood textures, customized board felts, and procedural audio synthesis.
- **Zero-Dependency**: Runs completely offline directly in any modern browser without needing build tools, servers, or external downloads.

## How to Play
1. **Directly offline (No server needed)**:
   - Double-click `play_offline.bat` or simply open `index.html` in your web browser.
2. **Via Local HTTP Server**:
   - Double-click `start_server.bat` (serves the game on `http://localhost:8080`).
